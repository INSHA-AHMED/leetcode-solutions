## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

Use two pointers, one starting from the beginning of the array and the other from the end. Swap the characters at these positions and move both pointers toward the center until the entire string is reversed.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

The string is reversed in-place without creating another array.
